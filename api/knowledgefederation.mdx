# knowledgeFederation

Federated knowledge import and search across multiple semantic web sources.  Queries Wikidata (SPARQL), DBpedia (SPARQL), and ConceptNet (REST) in parallel or in sequence to build knowledge clusters around seed entities. Results are merged, deduplicated by confidence, and organized into clusters using DFS connectivity analysis.  All query methods validate input and return empty arrays on invalid input rather than throwing, so callers can safely `await` without wrapping in try/catch.

## Location
`src/services/knowledgeFederation.js`

## Methods


### importKnowledgeCluster

Imports a multi-level knowledge cluster centered on a seed entity. Level 0 imports the seed; each subsequent level imports related entities discovered from the previous level, up to `maxDepth`. Returns immediately with an error-shaped result (no throw) if `seedEntity` is empty or invalid.

**Parameters:**

- `\{string\} seedEntity - Human-readable entity name to start from (e.g. `'Immanuel Kant'`).`
- `\{Object\} [options=\{\}] - Import configuration.`
- `\{number\} [options.maxDepth=2] - Number of relationship hops to follow.`
- `\{number\} [options.maxEntitiesPerLevel=10] - Max entities imported per depth level.`
- `\{boolean\} [options.includeRelationships=true] - Whether to discover relationships between entities.`
- `\{string[]\} [options.includeSources=['wikidata','dbpedia']] - Knowledge sources to query.`
- `\{function(Object): void\} [options.onProgress] - Progress callback called with `\{ stage, entity, level \}`.`

**Returns:** \{Promise<KnowledgeClusterResult>\} Cluster result object.

### findRelatedEntities

Finds entities related to the seed via each source's relationship function. Results are sorted by confidence (descending) and deduplicated by target name.

**Parameters:**

- `\{number\} [options.limit=10] - Maximum relationships to return.`

**Returns:** \{Promise<Relationship[]>\} Related entity relationships, deduplicated and ranked.

### federatedSearch

Searches all registered knowledge sources in parallel and merges results. Results below `minConfidence` are filtered out. Returns an empty array (no throw) if the query is empty or invalid.

**Parameters:**

- `\{string\} query - Search query string.`
- `\{Object\} [options=\{\}] - Search options.`
- `\{string[]\} [options.sources] - Source keys to include (default: all).`
- `\{number\} [options.limit=20] - Maximum results to return.`
- `\{number\} [options.minConfidence=0.5] - Minimum confidence threshold.`
- `\{boolean\} [options.includeSnippets=true] - Whether to include description snippets.`

**Returns:** \{Promise<Array<\{title: string, snippet: string, uri: string, confidence: number, source: string\}>>\} Merged, ranked results.
