# sparqlClient

SPARQL query client for Redstring's semantic web integration.  Provides a singleton `SPARQLClient` instance pre-configured for Wikidata, DBpedia, and Schema.org. Features include: - Per-endpoint rate limiting (queued, not dropped) - 1-hour result cache keyed by endpoint + query hash - SSRF guard on caller-supplied endpoint URLs - Automatic GET/POST selection (GET for short queries and Wikidata to avoid CORS preflight)  Convenience wrapper functions (`executeQuery`, `findEquivalentClasses`, `searchEntities`, `testEndpoint`) delegate to the singleton.

## Location
`src/services/sparqlClient.js`

## Methods


### addEndpoint

Registers a custom SPARQL endpoint, replacing any existing entry with the same key. Validates the URL against the SSRF guard before storing. Clears any cached HTTP client for the key so the next query gets a fresh connection.

**Parameters:**

- `\{string\} key - Unique identifier for this endpoint.`
- `\{Object\} config - Endpoint configuration.`
- `\{string\} config.url - SPARQL endpoint URL (must be https or http, no private ranges).`
- `\{number\} [config.rateLimit=1000] - Minimum ms between requests to this endpoint.`
- `\{number\} [config.timeout=20000] - Request timeout in ms.`
- `\{Object\} [config.headers=\{\}] - Extra HTTP headers to include.`

### executeQuery

Executes a SPARQL SELECT query and returns the bindings array. Uses GET for queries under 4000 characters or targeting Wikidata (avoids CORS preflight); POST otherwise. Results are cached for 1 hour per endpoint+query. Applies per-endpoint rate limiting before each request.

**Parameters:**

- `\{string\} endpointKey - Registered endpoint identifier.`
- `\{string\} query - SPARQL SELECT query string.`
- `\{Object\} [options=\{\}] - Request options.`
- `\{AbortSignal\} [options.signal] - External abort signal; overrides the endpoint timeout.`
- `\{Object\} [options.headers] - Extra headers merged with endpoint defaults.`

**Returns:** \{Promise<Array<Object>>\} Array of binding objects; each key maps to `\{ value, type, ... \}`.
