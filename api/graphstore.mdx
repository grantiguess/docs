# graphStore

Creates a new visual group within a graph, optionally pre-populated with member instances. Groups are visual clusters of node instances. They store semantic metadata for RDF relationship tracking. Returns the new group ID.

### createGroup

Creates a new visual group within a graph, optionally pre-populated with member instances. Groups are visual clusters of node instances. They store semantic metadata for RDF relationship tracking. Returns the new group ID.

**Parameters:**

- `{string} graphId - ID of the graph to create the group in.`
- `{Object} [options]`
- `{string} [options.name='Group'] - Display name for the group.`
- `{string} [options.color='#8B0000'] - Hex color for the group border.`
- `{string[]} [options.memberInstanceIds=[]] - Instance IDs to include as initial members.`
- `{Object} [contextOptions] - Save context flags (isDragging, phase, etc.).`

**Returns:** {string|null} The new group ID, or null if the graph was not found.

### updateGroup

- `{string} groupId - ID of the group to update.`
- `{function} recipe - Immer recipe: `(group) => { group.name = '...'; }`.`
- `{Object} [contextOptions] - Save context flags.`

- `{Object} [contextOptions] - Save context flags.`

### ensureGroupAnchor

Ensures a group has a valid anchor instance, creating one or reassigning as needed. An anchor instance is the group's "representative" node on the canvas — it remains visible when the group is collapsed. If `preferredAnchorInstanceId` is provided and belongs to the group, it is promoted; otherwise the first member is used.

**Parameters:**

- `{string} graphId - ID of the graph containing the group.`
- `{string} groupId - ID of the group to anchor.`
- `{Object} [options]`
- `{string} [options.preferredAnchorInstanceId] - Instance ID to prefer as anchor.`
- `{Object} [options] - Remaining keys are passed as contextOptions.`

### convertGroupToNodeGroup

Converts a plain group into a node-group: associates it with a node prototype so the group renders as a "thing" with an expandable interior. If `createNewPrototype` is true, creates a new prototype with `newPrototypeName`/ `newPrototypeColor`; otherwise links the group to the existing `nodePrototypeId`. The group's anchor instance is converted to represent the prototype.

**Parameters:**

- `{string} graphId - Graph containing the group.`
- `{string} groupId - Group to convert.`
- `{string} nodePrototypeId - Prototype to link (ignored if createNewPrototype=true).`
- `{boolean} [createNewPrototype=false] - Create a new prototype instead of linking an existing one.`
- `{string} [newPrototypeName=''] - Name for the new prototype (requires createNewPrototype=true).`
- `{string} [newPrototypeColor='#8B0000'] - Color for the new prototype.`
- `{Object} [contextOptions] - Save context flags.`

---

### combineNodeGroup

Collapses a node-group back into a single node instance (the inverse of decompose). Removes all member instances and their edges from the graph, leaving only the anchor instance. The anchor's prototype retains its definition graph.

**Parameters:**

- `{string} graphId - Graph containing the group.`
- `{string} groupId - Node-group to combine.`
- `{Object} [contextOptions] - Save context flags.`

---

### decomposeNodeToGroup

Expands a node instance into a node-group by materializing its definition graph in place. Copies all instances and edges from the prototype's definition graph (at `definitionIndex`) into the active graph, then creates a group linking them to the source prototype. The original instance becomes the group anchor. Returns the new group ID.

**Parameters:**

- `{string} graphId - Graph containing the instance to decompose.`
- `{string} prototypeId - Prototype whose definition graph provides the expansion content.`
- `{number} [definitionIndex=0] - Which definition graph to expand (0 = first).`
- `{Object} [contextOptions] - Save context flags.`

**Returns:** {string|null} The new group ID, or null if decomposition failed.

Identifies pairs of node prototypes whose names are similar enough to be duplicates. Uses Levenshtein distance-based similarity. Returns pairs where both prototypes have similarity ≥ `threshold`. Does not modify state.

### mergeNodePrototypes

Merges a secondary node prototype into a primary, transferring all instances, edges, and definition graphs to the primary, then deletes the secondary. After the merge: all instances that referenced `secondaryId` are updated to reference `primaryId`; all edges referencing the secondary prototype's instances are preserved; all definition graphs previously owned by the secondary are re-owned by the primary.

**Parameters:**

- `{string} primaryId - The prototype to merge INTO (survives).`
- `{string} secondaryId - The prototype to merge FROM (deleted after merge).`

---

### mergeDefinitionGraphs

Merges the definition graphs of two prototypes according to a strategy. Strategies: - `'combine'` (default): Appends secondary's definition graph IDs to primary's list. - `'overwrite_with_primary'`: Secondary's definition graphs are removed. - `'overwrite_with_secondary'`: Primary's definition graphs are replaced with secondary's. - `'selective'`: Only graphs selected via `keepPrimary`/`keepSecondary` booleans are kept. All affected graphs have their `definingNodeIds` updated to reference `primaryId`.

**Parameters:**

- `{string} primaryId - Primary prototype ID.`
- `{string} secondaryId - Secondary prototype ID.`
- `{Object} [mergeOptions]`
- `{'combine'|'overwrite_with_primary'|'overwrite_with_secondary'|'selective'} [mergeOptions.strategy='combine']`
- `{boolean} [mergeOptions.keepPrimary] - For 'selective': retain primary's graphs.`
- `{boolean} [mergeOptions.keepSecondary] - For 'selective': retain secondary's graphs.`

### applyBulkGraphUpdates

Applies a batch of nodes, edges, and groups to an existing graph in one transaction. Handles deduplication: nodes with matching names are reused, edges between the same pair with the same type are updated rather than duplicated. Creates connection-type prototypes for named edge types on the fly. Accepts node names by string for edges, resolving them via a case-insensitive lookup map.

**Parameters:**

- `{string} graphId - Target graph ID.`
- `{Object} batch`
- `{Array<{name: string, color?: string, description?: string, x?: number, y?: number, prototypeId?: string, instanceId?: string}>} [batch.nodes=[]]`
- `{Array<{source: string, target: string, type?: string, directionality?: string, definitionNode?: Object}>} [batch.edges=[]]`
- `{Array<{name: string, memberNames?: string[], memberInstanceIds?: string[]}>} [batch.groups=[]]`

### createNewGraph

Creates a new graph paired with a defining prototype, and activates it. Both the graph and its owning prototype are assigned new UUIDs (unless `initialData.id` provides a specific graph ID). The graph is opened as a tab, its defining prototype is pinned to the right panel, and `activeDefinitionNodeId` is set to the new prototype.

**Parameters:**

- `{Object} [initialData]`

- `{string} [initialData.description] - Description text.`
- `{string} [initialData.color] - Hex color.`
- `{string|null} [initialData.typeNodeId] - Type assignment for the defining prototype.`

**Returns:** {string} The new graph ID.

### createComplexConcept

High-level helper for creating a concept prototype with an optional definition graph pre-populated with sub-concepts and relationships. Creates: (1) a prototype for the concept, (2) a definition graph if `subConcepts` are provided, (3) prototype+instance for each sub-concept inside that graph, (4) edges for each relationship, (5) optionally, an instance in `targetGraphId`.

**Parameters:**

- `{Object} conceptData`
- `{string} conceptData.name - Name for the main concept.`
- `{string} [conceptData.color] - Hex color.`
- `{string} [conceptData.description] - Description text.`
- `{Array<{name: string, color?: string, description?: string}>} [conceptData.subConcepts=[]]`
- `{Array<{source: string, target: string, type?: string}>} [conceptData.relationships=[]]`
- `{string|null} [conceptData.targetGraphId=null] - Graph to place the main concept instance in.`

**Returns:** {{prototypeId: string, definitionGraphId: string|null, instanceId: string|null, subConceptIds: Array, edgeIds: string[]}}
