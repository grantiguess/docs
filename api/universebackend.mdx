### openBackupsDB

Open (and lazily create) the IndexedDB database that holds pre-migration format backups for browser installs. Records are keyed by a composite `\{slug\}:\{version\}:\{isoTimestamp\}` string with a `slug` index for eviction.

---

### backupBeforeMigrationIfNeeded

Format-backup invariant (P0.5 / decision D4). Called at load time, AFTER raw bytes are parsed but BEFORE import/migration reshapes anything. If the file's format version is older than the current version, the original bytes are preserved so a migration bug can never be an unrecoverable loss. Best-effort: any failure here warns and returns — it must never block loading the universe.

**Parameters:**

- `\{Object\} universe - universe descriptor (provides slug)`
- `\{FileHandle|string\} fileHandle - Electron path string or browser FileHandle`
- `\{string\} rawText - the exact original file contents`
- `\{Object\} parsedData - JSON.parse(rawText), used only for version detection`

---

### backupToSiblingFile

Electron path: write a sibling backup file next to the universe file. Naming: `\{nameWithoutExt\}.v\{detectedVersion\}.bak.redstring`. Skipped if it already exists so repeated loads of the same old file don't pile up backups.

---

### backupToIndexedDB

Browser path: store a pre-migration backup in IndexedDB (no directory handle is available to write a sibling). Keeps at most 3 backups per slug, evicting the oldest by timestamp.
